# ChildStudy · 阿里云轻量应用服务器部署手册

> 适用：**Windows Server** 系统 · 访问形态 **http://公网IP:8000**（同源部署，无需 Nginx）· **整包迁移含数据库**
> 版本：v1.7.0+ · 更新：2026-09-02

---

## 一、为什么不需要 Nginx / 反向代理

本项目后端 `main.py` 已经做了「同源托管」：

- 前端 `vite build` 产物在 `frontend/dist`
- 后端启动时用 `StaticFiles` 把 `dist` 挂到 `/`，并提供 SPA 路由回退
- 前端 API 全部走相对路径 `/api`（见 `frontend/src/api/index.js`）

所以浏览器访问 `http://公网IP:8000` 时，**页面和接口来自同一个源**，天然无跨域问题，一个 FastAPI 进程（uvicorn）全部搞定。部署只做一件事：**把代码 + 数据库放到服务器并跑起来**。

---

## 二、需要安装的环境

| 组件 | 版本要求 | 说明 |
|------|---------|------|
| Python | ≥ 3.10 | 后端，安装时勾选 Add to PATH |
| Node.js | ≥ 18 | 仅首次构建前端 dist 需要，之后可卸载 |

> 阿里云轻量 Windows Server 通常是 2016/2019/2022，**默认不含 Python/Node**，需自行下载安装包（python.org / nodejs.org）。

## 三、打包清单（本机操作）

把下列内容拷贝成一个文件夹上传到服务器。**只带以下内容**，不要带 `.venv` / `node_modules`（体积大且不可跨机移植，服务器上重新装）。

```
ChildStudy/
├── VERSION
├── backend/
│   ├── .env                    # 配置文件（含密钥，服务器要按需改）
│   ├── main.py
│   ├── config.py
│   ├── database.py
│   ├── models.py
│   ├── schemas.py
│   ├── dependencies.py
│   ├── requirements.txt
│   ├── data/
│   │   └── childstudy.db       ★ 你的全部数据（约 1MB），必带
│   └── routers/                # 整个目录
│   ├── utils/                  # 整个目录
│   ├── seeds/                  # 整个目录
│   └── uploads/                # 如为空可建空目录
├── frontend/
│   ├── dist/                   ★ 已构建的前端产物（关键！）
│   └── package.json            # 服务器上如要重跑 vite build 用
└── start_server.bat            # 见下文，由本手册生成
```

**不要带**：`backend/.venv`、`frontend/node_modules`、`.git`、`*.log`、`__pycache__`。

> 传输方式：可用 WinSCP / FileZilla（SFTP），或服务器控制台「远程文件」上传；数据库必须保持 `backend/data/childstudy.db` 的相对路径不变。

## 四、服务器操作步骤

### 第 1 步：把文件夹放到服务器

推荐放到 `C:\ChildStudy`（避开有空格的中文路径，减少坑）。最终结构应为：

```
C:\ChildStudy\backend\...   C:\ChildStudy\frontend\dist\...   C:\ChildStudy\start_server.bat
```

### 第 2 步：安装 Python 与 Node

1. 安装 Python（勾选 **Add python.exe to PATH**）
2. 安装 Node.js LTS
3. 打开 PowerShell（管理员）验证：
   ```powershell
   python --version    # 应 ≥ 3.10
   node -v             # 应 ≥ 18
   ```

### 第 3 步：建后端虚拟环境并装依赖

```powershell
cd C:\ChildStudy\backend
python -m venv .venv
.\.venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

### 第 4 步：生成前端 dist（可选，如 dist 已带可跳过）

如果你打包时已带上 `frontend/dist`，本步可跳过。若想在服务器重建：

```powershell
cd C:\ChildStudy\frontend
npm install
npm run build      # 产出到 dist
```

### 第 5 步：检查 / 修改后端配置 `.env`

编辑 `C:\ChildStudy\backend\.env`，确认：

```
APP_HOST=0.0.0.0      # 必须，允许公网访问
APP_PORT=8000
APP_DEBUG=false
```

> **可选安全项**：`.env` 里 `JWT_SECRET` 建议改成服务器新随机串（改了旧 token 全部失效，需重新登录，但账号密码不受影响）：
> ```powershell
> python -c "import secrets; print(secrets.token_urlsafe(32))"
> ```
> `ALLOWED_ORIGINS` 因为同源访问**不影响**（页面和接口同源，无需 CORS），可保持默认。

### 第 6 步：放行防火墙端口 8000

```powershell
netsh advfirewall firewall add rule name="ChildStudy 8000" dir=in action=allow protocol=TCP localport=8000
```

### 第 7 步：启动服务（先手动验证）

```powershell
cd C:\ChildStudy\backend
.\.venv\Scripts\python.exe main.py
```

看到 `Uvicorn running on http://0.0.0.0:8000` 即成功。浏览器先访问服务器本机 `http://127.0.0.1:8000` 确认页面能开。

> 服务器本机自测 API：`http://127.0.0.1:8000/api/health` 应返回 `{"status":"ok",...}`

### 第 8 步：用 nssm 注册为开机自启服务（推荐，替代手动 bat）

Windows Server 桌面版用 nssm 最稳。下载 [nssm](https://nssm.cc/download) 解压：

```powershell
# 停止手动跑的进程后
cd C:\ChildStudy
.\nssm.exe install ChildStudy   # 弹窗配置：
#    Application path:  C:\ChildStudy\backend\.venv\Scripts\python.exe
#    Startup directory: C:\ChildStudy\backend
#    Arguments:         main.py
#    Startup -> Automatic
.\nssm.exe start ChildStudy
```

> 之后可用 `.\nssm.exe restart ChildStudy` 重启服务；改代码后改 main.py 无需重启（但改 .env 需重启服务）。

## 五、在阿里云控制台放行安全组端口（关键！别忘了）

轻量服务器**两层防火墙**：

1. **阿里云控制台安全组**：登录轻量应用服务器控制台 → 防火墙 → 添加规则 → 放行 TCP **8000**（来源 0.0.0.0/0）
2. **Windows 系统防火墙**：已在上文第 6 步放行

若只放 Windows 防火墙而漏了阿里云安全组，外网仍访问不通——**这是最常见漏配点**。

## 六、公网访问与验证

一切就绪后，在任何联网设备（手机 4G/5G 或公司网络）访问：

```
http://<你的公网IP>:8000
```

登录账号 `dad` / `dabao` / `xiaobao`（密码沿用本机数据里的密码）即可。

**首次用手机流量测**（避开和服务器同一 Wi-Fi 的场景），能确认是真正走公网。

## 七、安全提醒（面向公网务必重视）

| 事项 | 建议 |
|------|------|
| 密码强度 | 把 `dad/dabao/xiaobao` 密码改成强密码（现为 123456，公网极危险） |
| 登录接口 | 建议在阿里云防火墙只对可信 IP 放行 8000，或至少设强密码 |
| 数据备份 | 定期下载 `backend/data/childstudy.db` 回本地备份 |
| 系统补丁 | 服务器保持 Windows 自动更新 |
| 公网暴露面 | 这是家庭隐私数据系统，若长期公网使用，强烈建议后续上域名 + HTTPS（见下文进阶） |

> 改密码方式：登录后「系统设置 → 修改密码」，或用后端命令直接改库哈希（参考维护技能）。

## 八、进阶（可选）：绑域名 + HTTPS（80/443）

如需体验更像正式站点、且愿意备案域名，可加一层 Nginx（Windows 版）或直接用 `uvicorn` 的证书 + 阿里云 SSL：

1. 域名在阿里云备案
2. 申请免费 SSL 证书（阿里云数字证书管理）
3. 用 Nginx 反代 `8000 → 443`，配置证书
4. `.env` 里 `ALLOWED_ORIGINS` 追加 `https://你的域名`

届时访问 `https://域名` 无端口，更正规。需要时再展开细做。

## 九、无 HTTPS 时的安全加固（v1.7.1 已内置部分能力）

没有域名/证书无法上 HTTPS，只能靠「减少暴露面 + 访问控制 + 数据兜底」的多层防线。**内置能力已经写进后端代码，部署服务器即可用**；外层网络层需你在阿里云控制台操作。

### 9.1 代码内置（随本版代码上服务器即生效）

| 能力 | 说明 | 效果 |
|------|------|------|
| **登录防爆破限流** | 同一来源 IP 连续失败 5 次 → 临时锁定 15 分钟，返回 429 | 拦住密码爆破/撞库脚本 |
| **登录日志留痕** | 登录成功/失败/触发锁定均打印日志（含来源 IP） | 事后能查异常访问 |

> 触发锁定后，即使密码正确也会被拒（IP 维度），待锁定期结束自动恢复。
> 阈值/时长可用 `.env` 调整（默认 5 次 / 15 分钟）：
> ```
> LOGIN_MAX_FAILURES=5
> LOGIN_LOCK_MINUTES=15
> ```
> ⚠️ 注意：**限流按来源 IP**。若家里路由器重启导致对外 IP 变了，或手机流量登录，都可能误触发。设置过低会自锁（若家人被锁，可等 15 分钟或改小阈值重启）。

### 9.2 服务器上务必做（可复制命令）

**① 更换 JWT_SECRET**（服务器上生成随机密钥，替换 `backend/.env` 里的值）：
```powershell
python -c "import secrets; print(secrets.token_urlsafe(32))"
# 把输出粘到 backend/.env 的 JWT_SECRET= 后，然后重启服务
```
> 换了密钥后旧登录 token 全部失效，需重新登录（账号密码不受影响）。

**② 账号强密码**：登录后台把 `dad/dabao/xiaobao` 的 `123456` 全改成 ≥12 位强密码（系统设置 → 修改密码）。公网下弱口令是最大风险。

### 9.3 阿里云控制台操作（你动手）

**IP 访问白名单（效果最显著）**：登录轻量服务器控制台 → 防火墙 → 把 8000 规则的来源从 `0.0.0.0/0` 改成**你家宽带的公网 IP**，外人就扫描不到了。
- 查你家公网 IP：手机流量访问 `https://myip.ipip.net` 之类查公网出口 IP，或路由器 WAN 口状态。
- 家里 IP 变了会访问不了，需回控制台改一次。若嫌麻烦可先保持 0.0.0.0/0，但务必靠 9.2 的强密码 + 限流兜底。

### 9.4 数据库自动备份（Windows Server 计划任务）

数据库 `C:\ChildStudy\backend\data\childstudy.db` 是**唯一核心资产**，丢了全没。用系统自带「任务计划程序」每日自动复制一份到备份目录并保留最近 30 份。

**第 1 步**：新建备份脚本 `C:\ChildStudy\backup_db.bat`：
```bat
@echo off
set SRC=C:\ChildStudy\backend\data\childstudy.db
set BAK=C:\ChildStudy\backups
set DEST=%BAK%\childstudy_%date:~0,4%%date:~5,2%%date:~8,2%.db
if not exist "%BAK%" mkdir "%BAK%"
copy /Y "%SRC%" "%DEST%" >nul
forfiles /p "%BAK%" /m childstudy_*.db /d -30 /c "cmd /c del @path" 2>nul
echo backup done %date% %time%
```
> 说明：备份到 `C:\ChildStudy\backups`，文件名带日期，只保留最近 30 份。

**第 2 步**：注册每日计划任务（管理员 PowerShell）：
```powershell
schtasks /Create /TN "ChildStudyDB备份" /TR "C:\ChildStudy\backup_db.bat" /SC DAILY /ST 03:00 /RL HIGHEST /F
```
> 每天凌晨 3:00 自动备份。可运行 `schtasks /Query /TN ChildStudyDB备份` 查看，`schtasks /Run /TN ChildStudyDB备份` 立即手动跑一次验证。

**第 3 步**：验证：
```powershell
schtasks /Run /TN "ChildStudyDB备份"
dir C:\ChildStudy\backups
```
> 出现带当天日期的 `.db` 文件即成功。建议定期把这备份下载到本机/网盘，异地留存一份。

### 9.5 排查异常登录（事后监控）

登录日志会打在后端日志里。看是否有非你家的来源 IP 反复尝试：
```powershell
# 查看最近登录相关日志（nssm 服务模式日志路径视安装位置而定）
Get-Content C:\ChildStudy\backend\*.log -Tail 200 | Select-String "登录"
```
> 若看到大量来自陌生 IP 的「登录失败 / 登录防爆破」记录，说明有人在扫描，应立刻执行 9.3 的 IP 白名单。

## 附：常见坑速查

| 现象 | 原因 | 处理 |
|------|------|------|
| 外网打不开，服务器本机能开 | 阿里云安全组没放 8000 | 控制台防火墙加 TCP 8000 规则 |
| 打不开且安全组已放 | Windows 防火墙拦截 | netsh 放行 8000 |
| 页面能开但接口全 500 | 前端 dist 与后端版本不匹配 | 服务器上重新 `npm run build` |
| 改代码后不生效 | 后端进程还在跑旧代码 | nssm restart ChildStudy |
| 打开页面空白/路由 404 | dist 缺失 | 确认 frontend/dist 存在，重新 build |
