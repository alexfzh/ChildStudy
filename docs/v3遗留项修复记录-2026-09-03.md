### 2️⃣ element-plus 按需引入 ✅

**改动**:
- 新增 devDeps:`unplugin-auto-import` + `unplugin-vue-components`(ElementPlusResolver)
- `vite.config.js`:注册两插件;**删除 `manualChunks.element: ["element-plus"]`**(关键:保留会把全量包原样打回)
- `main.js`:移除全量 `app.use(ElementPlus)` 与全量 CSS;手动补函数式组件样式(message/message-box/notification/loading);`app.use(ElLoading)` 注册 v-loading 指令
- `App.vue`:`<el-config-provider :locale="zhCn">` 包裹全模板接管 locale(原 `app.use(ElementPlus,{locale})` 已删)
- `style.css`:移动端 `.el-table/.el-select-dropdown` 等 3 条覆盖补 `!important`——按需化后组件 CSS 变 lazy 后载,同特异性会被反压

**效果(实测)**:
| 指标 | 修复前 | 修复后 |
|---|---|---|
| element JS chunk | 938KB 单包(gzip 301KB) | 无单包;最大按需 chunk 103KB(el-date-picker)+ 90KB(el-table)+ 28KB(el-form-item),其余散入各页 lazy chunk |
| 首屏 element 开销 | 全量 | 仅首页用到的组件 |

echarts 541KB 警告仍在(charts 本体大,不在本次范围)。
