## 四、部署注意

1. 改后端代码后需重启（`APP_DEBUG=false` 不热更）。
2. 限流默认关闭；如暴露公网/跨设备，在 `.env` 设 `RATE_LIMIT_PER_MINUTE=60~120` 并前置 Caddy（`APP_HOST=127.0.0.1`）。
3. Alembic 骨架默认不启用；若要启用版本化迁移，先 `pip install alembic` 再 `alembic stamp baseline`，之后逐步废弃 `database.py` 的 `_migrate_*` 启动期迁移。
4. `/uploads` 静态挂载仍保留；若对作品图隐私要求高，前端可改用 `/api/project-works/{id}/image`（带 Bearer）。
