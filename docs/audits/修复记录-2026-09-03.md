# ChildStudy 审计问题修复记录（2026-09-03）

> 对应报告：`审计报告-2026-09-03.md`。本文件记录审计发现的每一项问题如何落地修复、改动位置与验证结果。
> 验证环境：backend `.venv` (Python 3.14.6) → `ruff check` 全过；`pytest` 214 passed / 2 skipped（含新增 5 个回归测试）；前端 `vite build` 成功。

## 1. [High] 默认 JWT 占位密钥可启动 → fail-fast

**改动**
- `backend/config.py`
  - 抽出常量 `DEFAULT_JWT_SECRET`（原占位字符串）。
  - `model_post_init` 中：若 `jwt_secret == DEFAULT_JWT_SECRET` 直接 `raise ValueError` 拒绝启动；保留长度 <32 的 warning。
- `backend/tests/conftest.py`：在 import `config` 之前 `os.environ.setdefault("JWT_SECRET", "test-secret-not-for-production-0123456789abcdef")`，保证测试环境不命中占位密钥、不触发 fail-fast。

**效果**：漏配 `.env` 时应用启动即崩溃，杜绝用公开占位密钥伪造任意角色 token。已部署环境 `.env` 含强随机密钥，不受影响。

## 2. [Medium] AIReports.vue 的 v-html XSS → 链接 href 转义

**改动**
- `frontend/src/views/AIReports.vue`：`renderMarkdown` 的链接处理逻辑新增 `escapeAttr()`，对写入 `href` 的 URL 转义 `& " < >`，关闭「安全协议 + 空格 + 引号」的属性逃逸 XSS。正文 `<`/`>` 已在入口处转义，无残留注入点。

**说明**：`renderMarkdown` 本身已是自实现的小型渲染器（非 DOMPurify），正文 HTML 在首步已 escape。唯一风险点是 `href` 属性注入，已通过转义彻底封堵；未引入第三方依赖。

## 3. [P1] 上传作品图片不可见 → 挂载 /uploads 静态目录

**改动**
- `backend/main.py`：在 SPA catch-all 之前增加 `app.mount("/uploads", StaticFiles(directory=./uploads))`。文件名由服务端生成（`work_{id}_{ts}.{ext}`），不可枚举；家庭局域网场景可接受公开回取。`project_works` 写入的 `image_path = /uploads/project_works/{fname}` 现可被前端 `<img>` 直接加载。

## 4. [P1] 考试创建后不自动发积分 → 创建成功即发分

**改动**
- `backend/routers/rewards.py`：抽出可复用核心 `async def grant_exam_reward(db, exam_id)`，与原 `/exam-reward` 端点共用（幂等：同一 exam 只发一次积分、成就、段位）。
- `backend/routers/exams.py`：`create_exam` 提交考试后调用 `await grant_exam_reward(db, exam.id)`；异常被 try/except 包住，发分失败不影响考试记录本身。
- 新增回归测试验证自动发分 + 幂等（重复触发不产生双倍积分）。

## 5. [Low] /system/version 回显 DB 绝对路径 → 去敏感化

**改动**
- `backend/routers/system.py`：`VersionInfo.database` 由 `settings.database_url.split("///")[-1]`（绝对路径）改为固定字符串 `"SQLite (本地文件)"`，消除信息泄漏。该端点为公开路由，泄漏绝对路径属低危信息暴露。

## 6. [Low] 无服务端登出 / 令牌吊销 → 实现真正的吊销

**改动**
- `backend/utils/security.py`：`create_jwt` 每次签发生成唯一 `jti`。
- `backend/models.py`：新增 `RevokedToken` 表（id, jti 唯一索引, revoked_at），由 `Base.metadata.create_all` 自动建表（无需手写迁移）。
- `backend/dependencies.py`：`get_current_user` 解码后校验 `jti` 是否在 `revoked_tokens` 中，已吊销 → 401。
- `backend/routers/auth.py`：`POST /api/auth/logout` 由 noop 改为：取当前 token 的 `jti` 写入 `revoked_tokens`（幂等），使旧 token 立即失效。
