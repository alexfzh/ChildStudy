## 四、残余风险与工程债（诚实披露）

以下为**当前仍客观存在**、但家庭单机场景下影响可控的项，按真实风险排序：

1. **SQLite 单写者限制**（架构级）：并发写入需串行。家庭单用户无碍；多端同时写可能偶发 `database is locked`。缓解：读写分离已用 async，写冲突概率低。
2. **Alembic 默认未启用**（刻意取舍）：启用会与 `database.py` 启动期 ALTER 迁移冲突。启用步骤已写在 `migrations/env.py` 顶部。当前库依赖启动期迁移仍正常。
3. **限流默认关闭**：仅家庭 LAN 安全；公网暴露前须在 `.env` 设 `RATE_LIMIT_PER_MINUTE` 并前置 Caddy（`APP_HOST=127.0.0.1`）。
4. **无 HTTPS 默认**：家庭 LAN 可接受明文（已警告）；公网前置 Caddy 模板即补 TLS。
5. **分页为 offset 非 cursor**：家庭数据量（百~千条）足够；账号数据过万后建议改 keyset 分页。
6. **`Exercise.bank_title` 设计债**：已用 `exercises.py` 显式 `load` 规避 lazy 问题，功能无碍，纯设计整洁度。
7. **单家庭功能未开放**：schema 就绪但功能未开放，当前无碍，非 bug。

**已确认消除的首轮风险**：IDOR 越权（已首轮验证）、原始 SQL 注入（全路由无）、密码哈希（PBKDF2 60 万迭代）、CORS 限定、`.env` git-ignore、上传白名单 + 服务端文件名。
