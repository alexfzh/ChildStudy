## 4. 安全性 (70/100)

### ✅ 优势
- **JWT**：不硬编码 secret（从 `.env` 读取）
- **登录锁定**：N-1 次失败 → 401，N 次 → 429（15 分钟锁定）
- **密码哈希**：使用 passlib/bcrypt（非明文）
- **CORS**：已配置（开发环境 wildcard，生产需收紧）
- **SQL 注入防护**：所有查询用 SQLAlchemy ORM / parameterized queries

### ⚠️ 风险点
1. **SQL 注入风险（Medium）**：
   - `database.py:83` `text(f"SELECT COUNT(*) FROM {table}")`
   - `database.py:159` `text(f"ALTER TABLE exams ADD COLUMN {col} FLOAT")`
   - **原因**：表名/列名不能 parameterize，但应使用白名单验证
   - **影响**：`table` 来自 `__tablename__`（ORM 模型），`col` 来自已知 schema，实际风险较低
   - **建议**：加 `if table not in ALLOWED_TABLES: raise ValueError`

2. **CORS wildcard（Low）**：
   - 当前 `allow_origins=["*"]`，生产环境应限制具体域名

3. **测试硬编码密码（Low）**：
   - `test_auth.py` 中 `"pw123456"`, `"secret123"` 等，仅测试文件，不影响生产

4. **`.gitignore` 缺项（Low）**：
   - `.pytest_cache/` 未列入 `.gitignore`
